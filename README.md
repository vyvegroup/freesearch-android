# FreeSearch

Free and open-source search engine Android app. No content filtering. No limits.

## Features
- WebView-based search engine
- DuckDuckGo integration (no SafeSearch by default)
- Android 7.0+ support (API 24)
- APK Signed v2 + v3
- Lightweight and fast

## Build
```bash
./gradlew assembleRelease
```

## CI/CD
Built automatically via GitHub Actions on push to `main`.
